## 🔑 Critical environment fact — BUILD IN WSL, NOT WINDOWS

This machine's **Windows has a system-wide broken AF_UNIX `connect()`** (`WSAEINVAL`;
bind works, connect fails). Confirmed in **both Java and .NET**, persists across reboot.
It is **not** Norton (uninstalled ghost), not Razer, not filter drivers, not firewall —
it's an OS-level Winsock/AFD defect. Because Gradle/Java `Selector.open()` needs an
AF_UNIX loopback pipe, **every Gradle build on Windows fails** with:
`java.io.IOException: Unable to establish loopback connection`.

**Do not waste time retrying Windows builds.** Build in WSL (Ubuntu). It works.
